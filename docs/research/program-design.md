# Program design and plan-generation rules

> **Scope:** research for the plan engine. It covers the split, exercise selection, periodisation, conditioning, the time budget, a sample week and the generation rules. Other briefs own mobility content, back-pain screening and red flags, diabetes and blood-pressure (BP) thresholds, technique, animation and speech.
>
> **Evidence tags:**
> - **[S]** a position stand or several meta-analyses
> - **[M]** one meta-analysis or several randomised trials
> - **[W]** small trials, or cadaver, animal or cross-sectional data
> - **[E]** expert opinion or an app heuristic
>
> Sources checked 2026-10-05.

## Key decisions

1. **Replace the body-part split.** Every muscle is trained 2–3×/week.
   - 6 days: Upper/Lower ×3, with squat, single-leg and hinge lower days.
   - 5 days: Upper / Lower / Push / Pull / Legs.
2. **Plan by movement-pattern slots,** filled from a catalogue that carries safety flags.
3. **Earn spinal load.** Go heavy first on spine-sparing lifts (leg press, hip thrust, dumbbell press, supported rows). Heavy squats and hinges unlock through a five-level ladder with objective gates.
4. **Simple blocks.**
   - Three 4-week phases, with deloads in weeks 4 and 8 and a taper in week 12.
   - Double progression with RIR (reps in reserve) targets.
   - No failure sets on lifts that load the spine.
5. **Cardio:**
   - Mostly zone 2 (easy, conversational pace) on low-impact machines.
   - 1–2 interval blocks a week, after upper-body days.
   - Post-meal walks make up the rest of ≥150 min/week.
6. **Deterministic time-fit** with a fixed cut order. Main lifts, ramp-up sets and back-profile trunk work are never cut.

## 1. Weekly structure and training variables

### 1.1 Evidence → rule

| Variable | Evidence | Rule |
|---|---|---|
| Frequency | 2×/week per muscle beat 1× ([Schoenfeld 2016](https://pubmed.ncbi.nlm.nih.gov/27102172/)) [M]. When volume is equated, frequency barely affects hypertrophy ([Schoenfeld 2019](https://pubmed.ncbi.nlm.nih.gov/30558493/)) [M] but still raises strength ([Pelland 2026](https://pubmed.ncbi.nlm.nih.gov/41343037/)) [M]. ACSM 2026: ≥2 sessions/week ([Currier 2026](https://pubmed.ncbi.nlm.nih.gov/41843416/)) [S] | Each muscle ≥2×/week |
| Weekly sets | ≥10 sets/muscle/week, with diminishing returns beyond ~18–20; ≥2 sets per exercise ([Currier 2026]) [S]. Count indirect sets as 0.5 ([Pelland 2026]) [M] | Fractional sets: 10–14 / 12–18 / 10–14 by phase |
| Load | ≥80% of one-rep max (1RM) maximises strength; 30–100% 1RM gives similar hypertrophy ([Currier 2023](https://pubmed.ncbi.nlm.nih.gov/37414459/)) [S] | Heavy first on spine-sparing lifts |
| Failure | Not needed ([Refalo 2023](https://pubmed.ncbi.nlm.nih.gov/36334240/)) [M]. Hypertrophy, but not strength, rises closer to failure ([Robinson 2024](https://pubmed.ncbi.nlm.nih.gov/38970765/)) [W]. ACSM: 2–3 RIR is sufficient | Main lifts 2–3 RIR; isolation may reach 0–1; flagged lifts ≥2 |
| RIR accuracy | People under-predict reps left by about 1, and are more accurate near failure and at ≤12 reps ([Halperin 2022](https://pubmed.ncbi.nlm.nih.gov/34542869/)) [M]. Novices shouldn't rely on RIR alone ([Helms 2016](https://doi.org/10.1519/SSC.0000000000000218)) [E] | Pair RIR with a rep range. RPE (rating of perceived exertion) = 10 − RIR ([Zourdos 2016](https://pubmed.ncbi.nlm.nih.gov/26049792/)) |
| Rest | Resting >60 s helps hypertrophy slightly, with no extra benefit past ~90 s ([Singer 2024](https://pubmed.ncbi.nlm.nih.gov/39205815/)) [M]. Trained lifters need >2 min for strength ([Grgic 2018](https://pubmed.ncbi.nlm.nih.gov/28933024/)) [M] | 150–180 s heavy; 90–120 s compound; 45–60 s isolation |
| Tempo | Reps of 0.5–8 s grow muscle equally; over 10 s is worse ([Schoenfeld 2015](https://pubmed.ncbi.nlm.nih.gov/25601394/)) [M]. ACSM 2009: 1–2 s per phase ([ACSM 2009](https://pubmed.ncbi.nlm.nih.gov/19204579/)) | 2–3 s down, ~1 s up |
| Order | Strength gains are larger when the lift comes early ([Currier 2026]) [S]. Lifting before cardio protects leg strength ([Eddens 2018](https://pubmed.ncbi.nlm.nih.gov/28917030/)) [M] | Main lift first, cardio last |
| Periodisation | A small 1RM edge in trained lifters, no hypertrophy edge ([Moesgaard 2022](https://pubmed.ncbi.nlm.nih.gov/35044672/)) [M]. Less important than overload (ACSM 2026) [S] | Three phases plus weekly progression |
| Concurrent cardio | No interference with hypertrophy or maximal strength ([Schumann 2022](https://pubmed.ncbi.nlm.nih.gov/34757594/)) [M]. Running interfered more than cycling in an older analysis ([Wilson 2012](https://pubmed.ncbi.nlm.nih.gov/22002517/)) [W] | 12 min of low-impact cardio is fine |

### 1.2 Why replace the current split

- Each muscle is trained only once a week.
- The days overrun: Hypertrophy-phase Leg Day has 27 sets, about 70 min by the §5 model.
- Spinal load clusters. Back Day deadlifts are followed 48 h later by back squats, Romanian deadlifts and leg presses, and deadlifts start in week 5 for every profile.
- Core Day leans on loaded flexion and rotation: cable crunch, Russian twist and hanging knee raise.

## 2. Back-safe exercise selection

### 2.1 Principles

- **Heavy lifting is earned, not banned.**
  - Exercise reduces chronic low back pain (~15/100) with no single type best ([Hayden 2021](https://pubmed.ncbi.nlm.nih.gov/34580864/)) [M].
  - Posterior-chain resistance training beat general exercise ([Tataryn 2021](https://pubmed.ncbi.nlm.nih.gov/33683497/)) [M].
  - Heavy deadlift training matched motor-control training at 2 years ([Aasa 2015](https://pubmed.ncbi.nlm.nih.gov/25641309/); [Michaelson 2016](https://pubmed.ncbi.nlm.nih.gov/27097785/)) [M].
- **Who benefits from deadlifts:** people with lower pain, lower disability and better back-extensor endurance ([Berglund 2015](https://pubmed.ncbi.nlm.nih.gov/25559899/)) [W]. These factors are the basis of the §2.4 gates.
- **Lumbar flexion:**
  - Lifting with a flexed lower back hasn't been shown to cause pain ([Saraceni 2020](https://pubmed.ncbi.nlm.nih.gov/31775556/)) [W]. Coach a neutral spine for tolerance, not out of fear.
  - Pig spines herniated under repeated loaded flexion, especially combined with twisting ([Callaghan 2001](https://pubmed.ncbi.nlm.nih.gov/11114441/); [Marshall 2010](https://pubmed.ncbi.nlm.nih.gov/19815318/)) [W, animal].
  - Loaded flexion and rotation drills add little, so they are dropped. Opposing view: [Contreras 2011](https://doi.org/10.1519/SSC.0b013e3182259d05).
- **Same stimulus, less lumbar demand:**
  - The trap bar lowers lumbar moment versus a straight bar ([Swinton 2011](https://pubmed.ncbi.nlm.nih.gov/21659894/)) [W].
  - Split squats built back-squat strength ([Speirs 2016](https://pubmed.ncbi.nlm.nih.gov/26200193/)) [W].
  - Rows are chest-supported.
- **Trunk work is anti-movement.**
  - Curl-ups give the most abdominal challenge for the least spinal compression ([Axler 1997](https://pubmed.ncbi.nlm.nih.gov/9219209/)) [W].
  - Progressions: [McGill 2009a](https://pubmed.ncbi.nlm.nih.gov/19154838/).
  - Carries add distinct demands ([McGill 2009b](https://pubmed.ncbi.nlm.nih.gov/19528856/)) [W].
- **NICE** recommends exercise for low back pain with or without sciatica, and no belts ([NICE NG59](https://www.nice.org.uk/guidance/ng59)) [S].

### 2.3 Spinal-loading ladder [E]

The ladder has two tracks, hinge (H) and squat (S). A slot may use anything at or below the user's unlocked level. Heavy work (≥80% 1RM, or ≤6 reps at ≤2 RIR) is allowed only at levels 3–4.

| Level | Hinge track | Squat track | Ceiling |
|---|---|---|---|
| 0 | glute-bridge, dowel hinge, back-extension-45 hold | Box sit-to-stand, partial leg press | RPE ≤5 |
| 1 | hip-thrust, cable-pull-through, kettlebell-deadlift from blocks | goblet-box-squat, supported split-squat | RPE ≤7 |
| 2 | trap-bar-deadlift with high handles, dynamic back-extension-45, kickstand single-leg-rdl | goblet-squat, step-up, loaded split-squat, depth-limited leg-press | RPE ≤7, ≥6 reps |
| 3 | trap bar with low handles, romanian-deadlift to mid-shin, rack-pull (no heavier than trap-bar load) | Front-loaded squat, rear-foot-elevated split squat, walking-lunges | RPE ≤8, ≥5 reps |
| 4 | deadlift | barbell-squat | RPE ≤8.5, ≥3 reps |

Starting levels:

| Profile | Start at |
|---|---|
| No back history | H3/S3 (beginners H2/S2) |
| Quiet back history | H2/S2 if the back module's screen is passed, otherwise H1/S1 |
| Irritable back | H0/S0, walking and clinician review |
| Active sciatica | Capped at H1 |

### 2.4 Gates to move up a level (all required) [E, from the cited evidence]

| Gate | Criterion | Basis |
|---|---|---|
| G1 Symptoms | At least 4 exposures over 2 or more weeks, each with: pain ≤3/10 during the exercise; pain back to baseline by next morning; no leg symptoms that spread or travel below the knee | Pain-monitoring model ([Silbernagel 2007](https://pubmed.ncbi.nlm.nih.gov/17307888/)), made stricter. Tolerable pain is acceptable ([Smith 2017](https://pubmed.ncbi.nlm.nih.gov/28596288/)); spreading symptoms are a warning ([May 2012](https://pubmed.ncbi.nlm.nih.gov/22695365/)) |
| G2 Competence | Stable lumbar position on every rep: a dowel held along the back keeps 3-point contact on hinges; the pelvis does not tuck at squat depth; the user can brace while breathing | Coaching standard |
| G3 Capacity | Top of the rep range at or below target RPE in 2 consecutive sessions | "2-for-2" ([AHA 2023](https://pubmed.ncbi.nlm.nih.gov/38059362/)) |
| G4 Trunk endurance (optional) | Left and right side-plank times within 5% of each other; flexor:extensor <1.0; side:extensor <0.75; extensor hold ≥60 s (L3) or ≥90 s (L4) | [McGill 1999](https://pubmed.ncbi.nlm.nih.gov/10453772/); [ratios](https://pmc.ncbi.nlm.nih.gov/articles/PMC9745951/). Hold times are [E] |
| G5 Neural (sciatica) | Neither an active straight-leg raise nor the bottom of a kickstand hinge reproduces leg symptoms, in two sessions | Hip flexion with dorsiflexion tensions the sciatic nerve ([Coppieters 2006](https://pubmed.ncbi.nlm.nih.gov/16838375/)) [W] |

**Promotion rules:**
- Stay at a level for at least 2 weeks.
- Move up at most one level per fortnight.
- Start each new level at about RPE 6.

**Drop a level for a week** if any of these occur:
- Leg symptoms spread.
- Pain goes above 5/10.
- Next-morning pain is ≥2 points above baseline.

**Hand off to the red-flag pathway** for new numbness, weakness or bladder/bowel change ([Finucane 2020](https://pubmed.ncbi.nlm.nih.gov/32438853/)).

## 3. 12-week periodisation

| | Foundation (wk 1–4) | Hypertrophy (wk 5–8) | Strength (wk 9–12) |
|---|---|---|---|
| Main lifts | 3 × 8–10 @ 3–4 RIR (RPE 6–7) | 3–4 × 6–10 @ 2–3 RIR | 3–5 × 4–6 @ 2–3 RIR (5–8 for spinal lifts below L4), plus a back-off set × 8 |
| Secondary compounds | 2–3 × 10–12 @ 3 RIR | 3 × 8–12 @ 2 RIR | 3 × 6–10 @ 2 RIR |
| Isolation | 2 × 12–15 @ 2–3 RIR | 2–3 × 10–15 @ 1–2 RIR (0–1 RIR on the last machine set) | 2 × 10–12 @ 1–2 RIR |
| Rest: main / secondary / isolation | 120 / 90 / 60 s | 120–150 / 90 / 60 s | 150–180 (≥180 at ≤5 reps) / 90–120 / 60 s |
| Fractional sets per muscle | 10–14 | 12–18 | 10–14 |
| Tempo | 3 s down, pause on the box | 2 s down | Controlled down, fast up |

These are the ACSM 2009 ranges (8–12 rep max early, then heavy 1–6 rep max with 3–5 min rest), narrowed for back safety and updated with [Grgic 2018] and [Singer 2024].

**Modifiers:**
- Beginners: −20% volume, +1 RIR, machine variants.
- Advanced: up to 18–20 sets, and heavy/light days in the Hypertrophy phase ([Moesgaard 2022]).
- Hypertension: ≥3 RIR on any lift with valsalvaRisk ≥1, no sets of ≤5 reps, and continuous breathing. The BP module finalises these.

**Deload, weeks 4 and 8:**
- Halve the sets.
- Hold the load, or cut it by up to 10%.
- Add 2 RIR.
- No ladder promotions.
- Zone 2 cardio only.

This matches coach consensus: a deload of about 7 days every 4–6 weeks ([Bell 2023](https://pubmed.ncbi.nlm.nih.gov/37730925/)) [E]. Reduce training rather than stopping: a full week off slightly blunted strength gains ([Coleman 2024](https://pubmed.ncbi.nlm.nih.gov/38274324/)) [W]. Deload early if two main lifts stall for 2 sessions while readiness is low.

**Week 12 taper and re-test [E]:**
- Cut sets by 40% and hold loads.
- Do rep-max tests to 1 RIR, on spine-sparing lifts only.
- Estimate the hinge and squat 1RM from a 5–8-rep set at RPE 8.
- No true 1RM attempts for back or hypertension profiles.

**Progression:**
- **Double progression.** Once every set reaches the top of the rep range at the target RIR, add load. AHA says "2 more repetitions in 2 consecutive sessions → +2–10%", and ACSM 2009 also uses +2–10%. Heavy spinal lifts (AX2/LM2, §7.2) and hypertension profiles need it in two sessions running.
- **Increments:**

  | Lift type | Increment |
  |---|---|
  | Lower-body compounds | +2.5–5% (≥2.5 kg) |
  | Upper-body compounds | +2.5% (1–2.5 kg, or the next dumbbell) |
  | Isolation | Add reps first |
  | Carries | +2 kg per hand |

  If the next dumbbell is a jump of more than 10%, extend reps to the top of the range + 2 first; rep progression works ([Plotkin 2022](https://pubmed.ncbi.nlm.nih.gov/36199287/)) [W].
- **Autoregulation.** RIR-based loading matched or beat percentage loading ([Helms 2018](https://pubmed.ncbi.nlm.nih.gov/29628895/); [Graham 2021](https://pubmed.ncbi.nlm.nih.gov/31009432/); [Hickmott 2022](https://pubmed.ncbi.nlm.nih.gov/35038063/)) [M].
  - If set 1 misses the target RPE by ≥1.5, adjust the next set by ±2.5–5%, once per exercise per session.
  - Beginners progress on reps only.
- **Regress.** If reps fall below the range, or set 1 is ≥1.5 RPE over target, cut 5% (10% if painful).
- **Stall.** After 3 sessions without progress, cut 10% or swap to a sibling exercise.
- **Back caps:**
  - Spinal lifts rise ≤5% per week.
  - If pain today is ≥2 above baseline, or leg symptoms are present, use the next-lower ladder variant [E].

## 4. Conditioning for leanness and glucose control

### 4.1 Evidence

- **Volume:**
  - ADA 2026: ≥150 min/week over ≥3 days, with no more than 2 consecutive inactive days; 2–3 resistance sessions a week; break up sitting every 30 min ([ADA 2026]) [S].
  - WHO: 150–300 min/week ([Bull 2020](https://pubmed.ncbi.nlm.nih.gov/33239350/)) [S].
  - Meaningful weight loss needs >250 min/week ([Donnelly 2009](https://pubmed.ncbi.nlm.nih.gov/19127177/)) [M].
  - Resistance training alone cut 1.6 kg of fat and added 0.8 kg of lean mass ([Lopez 2022](https://pubmed.ncbi.nlm.nih.gov/35977113/)) [M].
- **Intervals vs zone 2:**
  - High-intensity interval training (HIIT) gave similar fat loss in about 40% less time ([Wewege 2017](https://pubmed.ncbi.nlm.nih.gov/28401638/)) [M].
  - HIIT improves insulin resistance, especially in type 2 diabetes ([Jelleyman 2015](https://pubmed.ncbi.nlm.nih.gov/26481101/)) [M].
  - 10 × 60 s bike intervals lowered 24-hour glucose ([Little 2011](https://pubmed.ncbi.nlm.nih.gov/21868679/)) [W].
  - The ADA notes HIIT can briefly raise glucose, so monitor it.
- **Timing:**
  - Walking 10 min after each meal beat 30 min once a day: −12% post-meal glucose, −22% after dinner ([Reynolds 2016](https://pubmed.ncbi.nlm.nih.gov/27747394/)) [M].
  - After a meal beats before it, and sooner is better ([Engeroff 2023](https://pubmed.ncbi.nlm.nih.gov/36715875/)) [M]. Short walking breaks help too ([Buffey 2022](https://pubmed.ncbi.nlm.nih.gov/35147898/)) [M].
  - Fasted morning HIIT may raise glucose ([Kanaley 2022](https://pubmed.ncbi.nlm.nih.gov/35029593/)).
- **Order.** Lifting before cardio kept glucose steadier in type 1 diabetes ([Yardley 2012](https://pubmed.ncbi.nlm.nih.gov/22374639/)) [W]. This fits the app's mobility → strength → cardio order.
- **Back.** A progressive walking programme cut low-back-pain recurrence (hazard ratio 0.72) ([Pocovi 2024](https://pubmed.ncbi.nlm.nih.gov/38908392/)) [M].

### 4.2 Making the 12 minutes count

| Block | Prescription | When |
|---|---|---|
| Zone 2 | 2 min easy → 9 min at RPE 3–4/10 (full sentences possible) → 1 min easy | Default; lower days; deloads |
| Short intervals | 2 min easy → 6 × (30 s at RPE 7–8 + 60 s easy) → 1 min easy | 1×/week in Foundation, then 2×/week; after upper days only |
| Long intervals | 2 → 4 × (60 s at RPE 7 + 60 s easy) → 2 min | Alternative |
| Tempo | 2 → 8 min at RPE 5–6 → 2 min | When intervals aren't cleared |

- **Intensity:** use RPE rather than heart rate with β-blockers or autonomic neuropathy ([Kanaley 2022]).
- **Interval clearance:** intervals wait for medical-module clearance in uncontrolled hypertension, proliferative retinopathy, or insulin use without glucose monitoring.
- **Hypertension:** finish with ≥2 min easy ([AHA 2023]).
- **Diabetes:** train 15–60 min after a meal.

### 4.3 Modalities

| Modality | Back and sciatica notes |
|---|---|
| Incline treadmill (default) | Low impact. Incline suits backs that dislike extension: people with stenosis walked longer uphill ([Fritz 1997](https://pubmed.ncbi.nlm.nih.gov/9355058/)) [W]. Flexion-sensitive backs: 0–5% |
| Brisk walking | As above; ideal after meals. With neuropathy: smooth ground and good shoes |
| Recumbent bike\* | Trunk supported, non-weight-bearing (suits neuropathy); best for intervals. Sit upright if flexion provokes symptoms |
| Upright bike | Flexed posture; may aggravate flexion-sensitive sciatica [E] |
| Elliptical\* | Upright, low impact; hold the handles if balance is impaired |
| Rowing ergometer | Repeated loaded flexion at the catch; back pain is common in rowers ([Wilson 2021](https://pubmed.ncbi.nlm.nih.gov/33685861/)). Only from H3, in short bouts |
| Running | Runners have healthier discs ([Belavý 2017](https://pubmed.ncbi.nlm.nih.gov/28422125/)) [W], but impact can flare sciatica or calves. Gate: 30 min of symptom-free brisk walking, then walk–run |

### 4.4 When to add walks

Six sessions give 72 min of cardio, so most users need 80–180 min more.

1. **Under 150 min:** add 10–15-min post-meal walks, starting after the meal with the most carbohydrate.
2. **Fat loss:** 200–300 min/week, or 7,000–10,000 steps a day. Benefit plateaus at about 8,000–10,000 steps under age 60 ([Paluch 2022](https://pubmed.ncbi.nlm.nih.gov/35247352/)).
3. **Diabetes:** a daily post-meal walk, rest days included.
4. **Back history:** walk daily, building by about 10% a week to 30–45 min [E].
5. **Cardio cut by time-fit:** schedule a 12-min walk later that day.
6. **Sitting:** prompt movement every 30 min.

## 5. Time budgeting the 60-minute session

The 60 minutes split into 15 min of mobility (which is also the general warm-up), 33 min of strength (1,980 s; plan for 31–32 min) and 12 min of cardio.

### 5.1 Constants [E, from a 1–2 s-per-phase tempo]

| Reps | Compound (3.5 s/rep + 10 s) | Isolation (3 s/rep + 10 s) | Unilateral compound (both sides + 10 s) |
|---|---|---|---|
| 5 | 28 s | 25 s | 55 s |
| 8 | 38 s | 34 s | 76 s |
| 10 | 45 s | 40 s | 90 s |
| 12 | 52 s | 46 s | 104 s |
| 15 | 62 s | 55 s | 125 s |

- **Holds:** hold time + 5 s; for per-side holds, ×2 + 10 s.
- **Rest:**

  | Exercise | Rest |
  |---|---|
  | Heavy compound | 150–180 s |
  | Other compound | 90–120 s |
  | Between paired exercises | 60–75 s |
  | Isolation | 45–60 s |
  | Trunk | 30–45 s |

- **Transitions:**

  | Change | Time |
  |---|---|
  | Same station | 20–30 s |
  | New machine | 45–60 s |
  | Loading a bar | 60–90 s |
  | At home | 20–30 s |

- **Ramp sets:**
  - First main lift: 2–3 sets (~50%, 70%, 85%) taking about 3–4 min.
  - Second compound in the same pattern: 1 set.
  - Isolation: none. Exercise-specific warm-ups suffice ([Iversen 2021](https://pubmed.ncbi.nlm.nih.gov/34125411/)).
- **What fits in 33 min:**

  | Format | Exercises | Sets |
  |---|---|---|
  | Straight sets | 4–5 | 9–11 |
  | Paired sets and circuits | 5–8 | 13–18 |

  Typical block times:

  | Block | Time |
  |---|---|
  | Main lift plus ramp sets | ~10 min |
  | A 2 × 3-set pair | 9–12 min |
  | A 4-exercise circuit done twice | ~8 min |

### 5.2 Paired sets and supersets

- **Supersets:** same volume, strength and hypertrophy in less time. RPE, lactate and energy cost go up, but blood pressure does not ([Zhang 2025](https://pubmed.ncbi.nlm.nih.gov/39903375/)) [M].
- **Antagonist pairs** preserve reps and add volume per minute ([Paz 2017](https://pubmed.ncbi.nlm.nih.gov/28933712/); [Robbins 2010](https://pubmed.ncbi.nlm.nih.gov/20733520/)) [W].
- **Tri-sets** may need extra recovery ([Weakley 2017](https://pubmed.ncbi.nlm.nih.gov/28698987/)) [W].

| Allowed | Never |
|---|---|
| Upper-body antagonists (press ↔ row, curl ↔ triceps) | With the main squat or hinge, or any AX2, LM2 or VR2 exercise (§7.2) |
| Upper-body accessory ↔ lower-body isolation | Two exercises that load the back extensors |
| Accessory ↔ anti-movement core | Two lower-body compounds |
| Circuits of up to 4 isolation lifts | Stations far apart (user toggle) |

- **Heavy squat and hinge sets:** only unloaded fillers between sets.
- **Hypertension:** rest ≥60 s between paired exercises [E].
- **Data model:** pairs map to `SupersetGroup`.

### 5.3 Auto-fit algorithm

```ts
function fitDay(day: DayPlan, p: Profile, budget = 1980) {
  let t = estimate(day);  // sets + rests (last dropped) + ramps + transitions
  for (const c of CUT_ORDER) while (t > budget && c.ok(day, p)) { c.apply(day); t = estimate(day); }
  for (const g of GROW_ORDER) while (t < budget - 150 && g.ok(day, p)) { g.apply(day); t = estimate(day); }
  if (t > budget) day.warning = `over by ${t - budget}s`;  // offer: extend, or move a block
}
const CUT_ORDER = [
  pairEligibleAccessories,      // §5.2
  trimIsolationAndTrunkRest,    // floors 45 s / 30 s; never compounds
  dropThirdIsolationSet,        // floor 2 sets
  dropLowestPriorityAccessory,  // duplicate isolation > calves/arms > delts > secondary → debt ledger
  secondaryCompoundMinusOneSet, // floor 2
  shortenCardioTo8,             // diabetes floor 10 min
];
// NEVER CUT: main-lift sets, ramp sets, main-lift rest, back-profile trunk slot
const GROW_ORDER = [repayDebtLedger, addMainLiftSet, addSetToUnderTargetMuscle, extendCardioTo15];
```

The debt ledger records each muscle's weekly set target. Cut sets move to the next day with slack, but never to the day before that muscle's heavy day [E].

  - Uncontrolled hypertension blocks strength sessions until cleared.
- **Diabetes:**
  - Cardio floor of 10 min.
  - No 2-day gaps.
  - Train after meals.
  - Intervals need glucose monitoring.

  - Neuropathy: prefer the recumbent bike.

- **Sciatica side [E]:**
  - Begin unilateral sets on the affected side.
  - Shorten neural-tension ranges on that side.
  - Log reps per side; if the affected side lags by more than 15%, add 1 weekly set to it.

### 7.5 Substitution logic

1. **Slot:** each slot is a pattern plus a role, with a profile-ordered candidate list. For example, a back-history main hinge is trap-bar-deadlift > kettlebell-deadlift > cable-pull-through > hip-thrust.
2. **Filter:** equipment → excluded flags → ladder level → G5 → user dislikes.
3. **Pick:** take the top survivor and keep it for the phase; rotate to a sibling at phase change.
4. **Fall back:** follow `regressionId` down to bodyweight. Never leave a slot empty.

| Gym | Home (dumbbells, bench, bands) | Minimal |
|---|---|---|
| lat-pulldown | Band-assisted pull-up | Band pulldown |
| Cable or machine rows | Chest-supported dumbbell row | Band row |
| machine-chest-press, cable-fly | dumbbell-bench-press, dumbbell fly | push-ups |
| leg-press | goblet-squat, split-squat | Tempo split-squat |
| hamstring-curl | Slider curl | Band curl |
| trap-bar-deadlift | Dumbbell deadlift | Single-leg glute-bridge |
| Cable accessories | Band versions | Band versions |
| Cardio machines | brisk-walking | brisk-walking |

### 7.6 Pseudo-code

```ts
function buildPlan(p: TrainingProfile): WeekPlan[] {
  const caps = deriveCaps(p);   // §7.4 → excludedFlags, rirFloors, repFloors, ladder
  return range(1, 12).map(week => {
    const phase = week <= 4 ? 'foundation' : week <= 8 ? 'hypertrophy' : 'strength';
    const mode = [4, 8].includes(week) ? 'deload' : week === 12 ? 'taper' : 'normal';
    const days = TEMPLATES[p.daysPerWeek].map(d => ({ ...d,
      blocks: d.slots.map(s => prescribe(selectForSlot(s, p, caps), s, phase, mode, caps, p)) }));
    balanceWeeklyVolume(days, TARGETS[phase][p.experience]);
    days.forEach(d => { pairBlocks(d, caps); fitDay(d, p); d.cardio = buildCardio(d, p, phase, mode); });
    return { week, phase, mode, days };
  });
}

function prescribe(ex, slot, phase, mode, caps, p) {
  let rx = { ...PHASE_TABLE[phase][slot.role] };
  if (ex.flags.VR >= 1) rx.rir = Math.max(rx.rir, caps.rirFloorVR);      // 3 with hypertension
  if (ex.flags.AX === 2 || ex.flags.LM === 2) rx.rir = Math.max(rx.rir, 2);
  rx.reps.lo = Math.max(rx.reps.lo, caps.repFloor(ex));                  // 6 HTN; 5 spinal < L4
  if (mode === 'deload') rx = { ...rx, sets: Math.ceil(rx.sets / 2), rir: rx.rir + 2 };
  if (mode === 'taper') rx = { ...rx, sets: Math.max(2, Math.round(rx.sets * 0.6)) };
  if (ex.unilateral && p.sciatica) rx.sideOrder = affectedFirst(p.sciatica.side);
  return { ex, rx };
}

function afterSession(log: SessionLog, p: TrainingProfile) {
  for (const e of log.exercises) {
    if (e.painDuring > 5 || e.legSymptomsSpread) { regressLadder(p, e.track); continue; }
    const top = e.sets.every(s => s.reps >= e.rx.reps.hi && s.rpe <= 10 - e.rx.rir);
    const need = e.flags.AX === 2 || e.flags.LM === 2 || p.hypertension ? 2 : 1;
    if (top && streak(e) >= need) bumpLoad(e);
    else if (e.sets.some(s => s.reps < e.rx.reps.lo) || e.sets[0].rpe >= 11.5 - e.rx.rir) reduceLoad(e, 0.05);
    if (stalled(e, 3)) reduceLoad(e, 0.10);
  }
  updateGates(p, log);   // G1–G5; at most one promotion per 14 days
}
```

- **Diabetes and BP modules:** run pre-session checks and may override `rirFloor`, `noIntervals`, `excludedFlags` or `blockSession`.
- **Mobility module:** honours NTs2, HB and SF2.
